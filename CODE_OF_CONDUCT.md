# Code of conduct

This adapter is a small project maintained at
github.com/mananlalwani/handover-gmessages. This code of conduct
follows the spirit of the Contributor Covenant and is kept short so
it fits how this project works.

## Expected behavior

Be respectful and direct. Assume good intent. Focus on the technical
issue, keep discussion on topic, and accept that maintainers may
decline a change with a short explanation.

## Unacceptable behavior

Harassment, insults, threats, unwanted contact, publishing private
information, and disruptive behavior are not acceptable in issues,
pull requests, discussions, or project chat.

## Scope

This code applies to project spaces including GitHub issues, pull
requests, discussions, and related communication about this adapter.

## Reporting

Report concerns by opening a private vulnerability report or by
contacting the maintainers privately. Never post credential bundles,
cookies, tokens, keys, pair codes, or message content in a public
GitHub issue. See SECURITY.md for what to exclude from public
reports.
